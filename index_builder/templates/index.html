Running KPM over SSH

Getting in — KOReader's SSH server listens on port 22 as root. Add your public key to koreader/settings/SSH/authorized_keys to skip the password.

ssh root@<kindle-ip>

Don't worry if the Kindle won't answer ping: its firewall drops ping, so it looks offline when it isn't. Try ssh instead.

Running commands — in a shell the ; is a syntax error, and kpm isn't on the path. Drop the ; and alias the full path once per session (home is in /tmp, so a profile won't survive a reboot):

alias kpm=/var/local/kmc/bin/kpm

Then every command above works without the ;, e.g. kpm update or kpm install <id>.
